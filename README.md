# Lenskart Eyewear Retail Database

## Overview

This repository contains the **Business Requirements Analysis (BRA)** and **Requirement Analysis** documents for the **Lenskart Eyewear Retail Database** project. The project focuses on designing a relational database using **Oracle SQL** to efficiently manage the core operations and business data of an online eyewear retail platform.

## Problem Statement

The rapid growth of online eyewear shopping has increased the need for efficient management of customer information, eyewear products, brands, categories, inventory, orders, payments, and customer reviews. Managing this data manually or through unstructured systems can lead to data redundancy, inconsistencies, inventory errors, delayed order processing, and difficulty in retrieving business information.

To overcome these challenges, this project designs a structured relational database that efficiently organizes business data, maintains data integrity, reduces redundancy through normalization, and supports the day-to-day operations of an online eyewear retail platform.

## Project Description

The proposed database is designed to manage the following information:

* Customer Management
* Product Management
* Brand Management
* Category Management
* Inventory Management
* Order Management
* Payment Management
* Wishlist Management
* Review Management

The project applies relational database concepts, normalization techniques, and entity relationships to design a structured and efficient database using Oracle SQL.
